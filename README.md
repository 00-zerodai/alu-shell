## 📖 Description

Welcome to the **Shell Scripting Basics** repository. This project is a collection of Bash scripts designed to teach the fundamentals of the Linux command line, shell navigation, file manipulation, and scripting logic.

Whether you are a beginner looking to understand the terminal or a developer refreshing your knowledge of automation, these scripts provide practical, hands-on examples of how to interact with the Linux kernel efficiently.

## 🎯 Learning Objectives

By the end of this project, you should be able to explain and implement:

*   **Navigation:** What is the absolute path of a directory and how to find it (`pwd`).
*   **File Management:** How to list files, create, move, and delete them (`ls`, `touch`, `mv`, `rm`).
*   **Permissions:** Understanding the `chmod` command and file modes (owner, group, others).
*   **Scripting logic:** How to use variables, loops (`for`, `while`), and conditionals (`if`, `else`).
*   **Input/Output:** How to manipulate standard input/output and use pipes (`|`).

## 🛠️ Requirements

*   **OS:** Ubuntu 20.04 LTS (or any modern Linux distribution)
*   **Shell:** Bash (Bourne Again Shell)
*   **Editor:** `vi`, `vim`, `emacs`, or `nano`
*   **Style Guide:** All scripts must pass `shellcheck` and follow the [Google Shell Style Guide](https://google.github.io/styleguide/shellguide.html).
